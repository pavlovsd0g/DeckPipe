# DeckPipe

**Музыка из Deezer и SoundCloud → общая библиотека на компьютере → плейлисты Rekordbox.**

DeckPipe находит уже сохранённые треки во всех ваших музыкальных папках, скачивает недостающие и добавляет их в Rekordbox. Поддерживается Windows x64; текущая версия — **0.6.0 beta**. Интерфейс на русском языке.

[Скачать сборку](https://github.com/pavlovsd0g/DeckPipe/releases) · [Сообщить о проблеме](https://github.com/pavlovsd0g/DeckPipe/issues)

## Установка

1. Откройте **Releases** по ссылке выше и выберите последнюю сборку.
2. В разделе **Assets** скачайте файл, заканчивающийся на **`-x64-setup.exe`**. Это обычный установщик. Альтернатива — **`-x64.msi`** для установки через Windows Installer; устанавливать оба варианта не нужно.
3. Закройте ранее запущенный DeckPipe, запустите установщик и следуйте его шагам.
4. Откройте DeckPipe из меню «Пуск» или ярлыка приложения.

Python, Node.js и Rust для использования не нужны. Приложение использует Microsoft Edge WebView2 Runtime; если его нет, установщику потребуется интернет для установки этого компонента. Установщики выпускаются **без цифровой подписи Windows**: система может показывать неизвестного издателя. Не отключайте защиту Windows для установки.

Архивы **Source code** содержат исходники, а не готовую программу. Отдельный `-x64.exe` из технического комплекта не заменяет установщик: приложению также нужна служба `deckpipe-backend.exe`.

## Первый запуск

### 1. Укажите всю музыкальную библиотеку

Нажмите **«Выбрать папку…»** в верхней панели и выберите одну общую папку, например `E:\Music`. Можно вставить путь в поле и нажать **«Сохранить»**. Дождитесь завершения сканирования.

Внутри могут находиться любые подпапки:

```text
E:\Music
├── House
├── Techno
└── Старые подборки
```

DeckPipe ищет треки во всей библиотеке. Если трек из «Лайков» уже лежит в папке `House`, он будет показан как найденный с фактическим путём. Перекладывать музыку в одну папку «Лайки» не требуется.

Если для конкретного плейлиста нужна другая папка, откройте его и нажмите **«Папка плейлиста…»**. Эта привязка задаёт место новых загрузок; уже найденные файлы остаются на своих местах. Названия папки и плейлиста могут различаться.

### 2. Подключите сервис

Нажмите **«Deezer: вход»** или **«SC: вход»** и выполните вход в открывшемся окне DeckPipe. Вход через Google может открыть дополнительное окно авторизации.

У DeckPipe собственный браузерный профиль, поэтому первый вход выполняется отдельно от Chrome, Firefox или другого обычного браузера. Сессия сохраняется между запусками, пока её не завершит сервис или вы сами. При повторном подключении сохранённый браузерный профиль используется снова.

Для SoundCloud после входа отметьте нужные источники и нажмите **«Импортировать выбранные»**. Источник также можно добавить по ссылке во вкладке **SoundCloud**.

**«Сменить аккаунт»** открывает вход в другой аккаунт. **«Выйти и забыть вход»** удаляет сохранённую авторизацию выбранного сервиса.

### 3. Откройте плейлист и скачайте недостающее

Выберите плейлист слева. В таблице видны наличие трека и путь к локальному файлу. Если найдено несколько подходящих файлов, выберите нужный и нажмите **«Использовать этот файл»**.

| Кнопка | Что делает |
| --- | --- |
| **Пересканировать** | Обновляет каталог и статусы после изменений файлов на диске. |
| **Папка плейлиста…** | Задаёт папку для новых загрузок этого плейлиста. |
| **Скачать выбранные** | Скачивает отмеченные отсутствующие треки. |
| **По порядку** | Обновляет номера файлов в папке плейлиста по порядку стриминга и докачивает недостающее. |
| **Новые вниз** | Докачивает недостающее, сохраняя существующие номера файлов. |
| **NN** | Управляет нумерацией имён файлов. |

Уже найденные в общей библиотеке треки повторно не скачиваются. Если накопитель с музыкой отключён, операции останавливаются до его возвращения. Доступность конкретного трека и качество исходника зависят от сервиса и аккаунта.

## Очередь загрузки

Очередь находится внизу окна.

- **«Свернуть загрузки» / «Показать загрузки»** скрывает или раскрывает список; загрузка продолжает работать.
- **«Скрыть завершённые»** очищает список завершённых и остановленных заданий. Скачанная музыка остаётся на диске.
- **«Остановить»** отменяет конкретное задание. Оставшиеся треки не скачиваются; временные незавершённые файлы удаляются. Полностью сохранённые треки остаются.

Во время остановки дождитесь статуса **«Остановлена»**. Завершение текущего сетевого запроса может занять некоторое время. Если очистке помешала ошибка диска, она будет показана явно.

## Синхронизация с Rekordbox

1. Сначала сохраните изменения в Rekordbox и **закройте его**.
2. В DeckPipe откройте нужный плейлист и нажмите **«→ Rekordbox»**.
3. Проверьте целевой плейлист и план изменений. Если одноимённых плейлистов несколько, выберите нужный.
4. Подтвердите применение. После успешной проверки результата можно снова открыть Rekordbox.

**Синхронизация добавляет только недостающие треки.** Треки, которые есть в Rekordbox, но отсутствуют в стриминге, сохраняются. Существующий порядок и данные треков не перезаписываются. Треки, уже найденные в коллекции Rekordbox по локальному файлу, используются повторно. Новые записи добавляются в конец в порядке источника; повторная синхронизация без новых треков ничего не меняет.

Перед записью DeckPipe проверяет исходный список, локальные файлы и актуальность просмотренного плана. При неполном источнике или неоднозначном совпадении применение блокируется. Перед изменениями создаётся резервная копия. Отмена закрывает просмотр и показывает короткое уведомление.

Если запись прервалась, используйте **«Rekordbox: восстановление»** в верхней панели. Сначала просмотрите и подтвердите восстановление; для последующей синхронизации откройте новый план.

## Исходный формат и WAV

В верхней панели выберите режим новых загрузок:

- **Исходный формат** — сохранить полученный файл.
- **WAV (+ исходник)** — дополнительно создать WAV и сохранить исходный файл.
- **WAV (удалять исходник)** — после успешной обработки оставить WAV.

Для уже добавленных треков Rekordbox используйте **«⇄ Проверить WAV»**. Приложение подготавливает и проверяет отдельные WAV-файлы, затем показывает план переключения путей. Эта операция сохраняет исходники и существующие идентификаторы треков. Возврат к исходным файлам выполняется через ту же кнопку.

Путь трека в коллекции Rekordbox общий для всех плейлистов, где он используется; перед переключением приложение показывает затронутые связи. Преобразование в WAV не повышает качество исходной записи.

## Логи и решение проблем

Во вкладке **«Логи»** видны время, этапы операций, результаты и ошибки. Новые записи появляются сверху; **«Показать ранее»** открывает историю. Журнал сохраняется между запусками и ограничен по размеру: старейшие записи постепенно удаляются. **«Обновить»** возвращает к последним событиям и автоматическому обновлению.

| Ситуация | Что сделать |
| --- | --- |
| Трек уже есть на диске, но не найден | Нажмите «Обновить каталог», проверьте общую папку и привязку плейлиста. При нескольких совпадениях выберите файл вручную. |
| Сервис просит войти снова | Нажмите кнопку аккаунта и повторите вход в окне DeckPipe. |
| Загрузка не завершилась | Посмотрите вкладки «Ошибки» и «Логи»; повторите незавершённый этап. |
| Синхронизация Rekordbox заблокирована | Закройте Rekordbox, проверьте доступность файлов и откройте свежий план. |
| Отключена флешка или внешний диск | Подключите тот же накопитель и обновите каталог. |

В сообщении о баге укажите действие, ожидаемый результат, время сбоя и соответствующие строки журнала. Пароли, токены и cookies не нужны. Журнал операций специально скрывает такие данные.
