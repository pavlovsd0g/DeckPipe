# DeckPipe для Windows

Синхронизация Deezer и SoundCloud с локальной музыкальной библиотекой. Текущий объём релиза — только Windows x64. macOS исключена из текущей разработки и критериев приёмки.

## Как организована музыка

1. Сначала пользователь явно выбирает **одну общую папку со всей музыкой**. Без этого синхронизация недоступна. Папка по умолчанию автоматически не назначается.
2. Приложение индексирует вложенные папки в постоянном каталоге SQLite. Уже скачанный трек учитывается в любом плейлисте стриминга, включая «Лайки»; рядом виден фактический путь.
3. Папку назначения можно отдельно привязать к плейлисту, даже если названия различаются. Явно привязанные внешние папки также входят в каталог. Привязка определяет место для новых загрузок.
4. Скачиваются только отсутствующие треки. Совпадение проверяется по идентификатору сервиса либо исполнителю, полному названию версии и длительности. Несколько кандидатов требуют выбора. Существующие файлы не перемещаются ради структуры стриминга.

При недоступном носителе синхронизация останавливается. Пересканирование обнаруживает перемещения, удаления и замену файлов. Каталог хранится в профиле приложения отдельно от музыки; `.deckpipe.json` остаётся состоянием операций в каждой папке.

## Подключение сервисов

Вход открывает обычный браузер. Для текущей инженерной сборки подготовлен помощник **Firefox для Windows**: расширение передаёт выбранную сессию нативному компоненту, приложение проверяет её и сохраняет через Windows DPAPI. В интерфейс приложения пароли и токены не возвращаются.

Пакет расширения пока не подписан Mozilla. Постоянная установка и настоящий вход ещё требуют приёмки; инструкция находится в [release/auth-helper/README.md](release/auth-helper/README.md). Chrome и Edge требуют отдельных пакетов и проверки.

SoundCloud сохраняет существующие `yt-dlp`/api-v2 механизмы чтения источников, лайков и загрузки. Создание плейлистов SoundCloud и одинаковый набор операций с Deezer не являются условием текущего релиза. Неполная коллекция или отказ сервиса показываются явно. Неудавшееся добавление в Deezer хранится отдельно от локальной загрузки и повторяется с проверкой содержимого плейлиста.
